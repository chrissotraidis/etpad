# ETPad 0.1.1

ETPad 0.1.1 fixes playing on a TV or monitor connected to an iPad. Wolfenstein: Enemy Territory on iPad, built on ET: Legacy 2.86.2; still a preview.

## What's new

- **Right on a TV.** When iPadOS shows ETPad on a TV or monitor (an extended display), the game now comes up the right way up and fills the screen; the iPad no longer limits it to landscape, which left it rotated or squeezed on the external screen ([#4](https://github.com/chrissotraidis/etpad/pull/4)).
- **No black screen on a TV.** Going full screen used to switch the display's mode, which iPadOS refuses for an external display, so the TV stayed black. ETPad now keeps full screen without switching the screen's mode.

## Install

Download `ETPad-unsigned.ipa` and sign it with your own Apple ID using Sideloadly, AltStore or Xcode, or build your own copy with [PadMint](https://github.com/chrissotraidis/padmint). Requires iPadOS 16 or later. Bundle ID `com.chrissotraidis.etpad`, version 0.1.1 (2). Install it over 0.1.0 with the same Apple ID; your game data and settings stay.

## Checked

- A development-signed build of this commit on an iPad Pro 12.9-inch (6th generation) connected to a 1280×720 TV, November 2026: installed in place over the existing app with data kept, opened from PadMint and played.
- PadMint player check (Apple Python 3.9, empty PadMint folder, fresh clone): passed. The IPA, recipe and `SHA256SUMS` pass `padmint audit` and the private release gate, and the IPA passes ETPad's package audit. It has the same 3,274 entries as 0.1.0's.
